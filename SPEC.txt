====================================
  簡易記帳網站 規格書
====================================
版本：v2（2026-10-13）
v2 新增：模擬資料、趣味小統計、三張圖表、深色／淺色切換


一、專案概述
------------------------------------
一個單頁式（Single Page）的個人記帳網站，讓使用者快速記錄每日收入與支出，
並透過統計與圖表了解自己的花費。
不需登入、不需後端，資料存在瀏覽器的 localStorage。
第一次打開時會自動放入模擬資料，打開就有內容可看。


二、技術架構
------------------------------------
  前端      ：純 HTML + CSS + JavaScript（不使用框架、不使用外部圖表套件）
  圖表      ：自己用 SVG / HTML 畫，離線也能使用
  資料儲存  ：瀏覽器 localStorage
  執行方式  ：直接用瀏覽器開啟 index.html

  檔案結構：
    所有 HTML、CSS、JavaScript 都寫在同一個 index.html 裡，
    方便直接部署到 GitHub Pages。
      <style>             樣式、深色／淺色配色
      <script> 模擬資料段 產生模擬資料
      <script> 圖表段     圖表繪製與滑鼠提示框（tooltip）
      <script> 主程式段   資料存取、表單、篩選、摘要、趣味統計、主題切換

  部署：
    原始碼放在 GitHub，使用 GitHub Pages 從 main 分支根目錄公開網站


三、功能需求
------------------------------------
3.1 新增紀錄
  欄位：
    - 類型：收入 / 支出（必填）
    - 金額：正整數（必填，> 0）
    - 分類：下拉選單（必填），切換類型時選項跟著換
        支出：餐飲、交通、購物、娛樂、居住、其他
        收入：薪資、獎金、其他
    - 日期：預設今天（必填）
    - 備註：文字，最多 50 字（選填）
  按「新增」後加入清單並清空金額與備註。
  欄位不合法時顯示錯誤訊息，不新增。

3.2 紀錄列表
  - 依日期由新到舊排序，標題旁顯示筆數
  - 每筆顯示：分類色點（僅支出）、日期、分類、備註、
    金額（收入綠色 +，支出紅色 -）
  - 每筆有「刪除」按鈕，刪除前跳出確認
  - 列表最高 420px，超過可捲動

3.3 篩選
  - 依月份篩選（input type="month"），預設本月
  - 勾選「全部」顯示所有紀錄，此時月份選擇器停用

3.4 摘要
  - 顯示目前篩選範圍內的：總收入、總支出、餘額（收入 - 支出，負數顯示紅色）

3.5 趣味小統計（4 格）
  依目前篩選範圍計算：
    最大筆支出    金額，並附上分類與備註
    最愛花錢在    金額最高的支出分類（不算「居住」），附金額與佔比
    平均每天花    總支出 / 天數，並附與上月比較
    手搖飲&咖啡   備註含「奶茶」「咖啡」「拿鐵」的筆數與總金額

  天數：
    - 選本月：用已過的天數
    - 選過去月份：用該月天數
    - 選「全部」：用第一筆到最後一筆的天數
  與上月比較：
    - 選本月：與上個月「同期」（1 號到今天的日期）比較
    - 選過去月份：與上個月整月比較
    - 選「全部」：不顯示
    - 支出變多顯示紅色，變少顯示綠色

3.6 圖表
  所有圖表滑鼠移上去都會顯示提示框，用鍵盤 Tab 聚焦也會顯示。

  (1) 近六個月收支（分組長條圖）
    - 以選擇的月份為最後一個月，往前共六個月
    - 每月兩根長條：收入（藍）、支出（橘）
    - 提示框顯示該月收入、支出、結餘
    - 目前選擇的月份標籤加粗
    - 視窗大小改變時重新繪製

  (2) 支出分類（甜甜圈圖）
    - 依目前篩選範圍，顯示各支出分類金額
    - 中間顯示總支出
    - 旁邊的圖例同時列出每個分類的金額與百分比
    - 每個分類固定一種顏色，不因排序或篩選而改變：
        餐飲 藍、交通 橘、購物 綠松、娛樂 黃、居住 粉紅、其他 綠

  (3) 每日支出（熱力日曆）
    - 顯示選擇月份的日曆，格子顏色越深代表當天支出越多
    - 有支出的日子依金額高低分成 5 級
      （以百分位數切分，避免房租那天讓其他天都變成最淺色）
    - 沒有支出的日子為灰底，未來的日子半透明
    - 提示框顯示當日支出總額與最大筆支出

3.7 模擬資料
  - 第一次打開（localStorage 沒有 ledger-records）時，
    自動產生近六個月到今天的模擬資料並儲存
  - 內容包含：每月 5 號薪水、1 號房租、15 號水電、三餐、手搖飲、
    平日交通、週末娛樂、隨機購物，其中一個月有績效獎金
  - 「重新產生模擬資料」按鈕：確認後以新的模擬資料取代全部紀錄
  - 「清空全部」按鈕：確認後刪除全部紀錄
    （清空後重新整理不會再自動產生）

3.8 深色／淺色模式
  - 預設跟隨作業系統的設定
  - 工具列有切換按鈕，文字顯示「切換淺色」或「切換深色」
  - 使用者選擇後存在 localStorage（key：ledger-theme），下次打開沿用
  - 圖表、日曆、卡片配色都跟著切換

3.9 資料保存
  - 每次新增 / 刪除 / 重新產生 / 清空後寫入 localStorage
  - 重新整理頁面後資料仍存在


四、資料格式
------------------------------------
4.1 紀錄
  localStorage key：ledger-records
  值為 JSON 陣列，範例：

  [
    {
      "id": "1728800000000",
      "type": "expense",
      "amount": 120,
      "category": "餐飲",
      "date": "2026-10-13",
      "note": "午餐"
    }
  ]

  欄位說明：
    id        string                   手動新增為建立時的時間戳；
                                       模擬資料為 demo-00001 格式
    type      "income" | "expense"     收入或支出
    amount    number                   正整數
    category  string                   分類名稱
    date      string                   YYYY-MM-DD
    note      string                   備註，可為空字串

4.2 主題
  localStorage key：ledger-theme
  值為 "light" 或 "dark"。沒有這個 key 時跟隨系統。


五、畫面配置
------------------------------------
  +------------------------------------------+
  |  記帳本                   [月份] [ ]全部  |
  |  [重新產生模擬資料] [清空全部]  [切換淺色] |
  +------------------------------------------+
  |   收入 $xx  |   支出 $xx  |   餘額 $xx    |
  +------------------------------------------+
  | 最大筆支出 | 最愛花錢在 | 平均每天花 | 手搖飲 |
  +------------------------------------------+
  |  近六個月收支                 #收入 #支出 |
  |  ||   ||   ||   ||   ||   ||             |
  +--------------------+---------------------+
  |  支出分類          |  YYYY年M月 每日支出  |
  |   ( 甜甜圈 )  圖例 |  日 一 二 三 四 五 六 |
  |                    |  . . # # . ...      |
  +--------------------+---------------------+
  |  新增紀錄                                 |
  |  [類型][金額][分類][日期]                 |
  |  [備註                        ][新增]     |
  +------------------------------------------+
  |  紀錄列表（N 筆）                          |
  |  o 10/13 餐飲 午餐           -120  [刪除] |
  +------------------------------------------+

  響應式：
    寬度 <= 720px：趣味小統計改 2 欄；甜甜圈與日曆改為上下排列
    寬度 <= 480px：表單欄位改為直向一欄


六、不在範圍內（本版不做）
------------------------------------
  - 帳號登入、多人同步
  - 後端 / 資料庫
  - 編輯既有紀錄
  - 匯出 / 匯入 CSV
  - 多幣別
  - 自訂分類
  - 預算設定與超支提醒


七、驗收標準
------------------------------------
   1. 第一次打開網站就看得到近六個月的模擬資料與圖表
   2. 可新增收入與支出，列表、摘要、趣味統計、圖表即時更新
   3. 金額為空、0、負數或小數時無法新增並顯示提示
   4. 刪除紀錄後摘要、統計與圖表正確更新
   5. 切換月份時，摘要、列表、甜甜圈、日曆、六個月長條圖都對應到該月
   6. 勾選「全部」時，摘要、列表、甜甜圈顯示全部資料
   7. 滑鼠移到長條、甜甜圈區塊、日曆格子上會顯示提示框
   8. 「重新產生模擬資料」與「清空全部」都會先確認再執行
   9. 深色／淺色切換正常，重新整理後維持上次的選擇
  10. 重新整理頁面後資料不遺失
  11. 手機寬度（375px）下版面正常、無水平捲動
  12. 畫面上不使用 emoji
